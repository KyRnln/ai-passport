# AIDA64 PC 状态监视器

把 AI Passport 变成 Windows 主机的随身状态屏。设备接入你的 Wi-Fi，连接
AIDA64 的 RemoteSensor 数据流，在 320 x 240 横屏上以黑底白字的点阵终端风格实时
显示 CPU / GPU / 内存占用率，以及 PC 的已运行时间。

本分支（`feature/aida64-pc-monitor`）只包含这个应用。上游基线、硬件能力契约
与文档索引仍在 [docs/README.zh_CN.md](docs/README.zh_CN.md)。

## 快速上手

1. 刷入固件：整机首次使用或要清空配置时刷合并镜像
   `FoloToy-AI-Passport-full.bin`（偏移 `0x0`）；只想升级应用时刷应用镜像
   `FoloToy-AI-Passport.bin`（偏移 `0x10000`，保留已保存的配置）。
2. 设备开机后长按 `OK` 进入设置页。
3. 选「Wi-Fi」条目，`OK` 进入确认页，再按 `OK` 开始配网：设备开启
   `AIPassport-Setup` 热点。
4. 手机连接该热点（密码 `aipassport`），打开 `http://192.168.4.1`，扫描并选择
   2.4GHz 网络，填入密码以及运行 AIDA64 的 PC 地址与端口，保存。
5. 设备验证 Wi-Fi 成功后自动回到监控主页：顶栏左侧是 PC 运行时间、右侧是电量，
   三张卡片是 CPU / GPU / 内存占用率。左下角状态从「连接中」变成「已连接」即表示
   数据已通；若一直显示「PC 离线」，按下面 AIDA64 一节核对字段。
6. 之后改配置：长按 `OK` → 「Wi-Fi」重新配网；换屏幕方向：设置页「方向」。

## 功能

- **占用率卡片**：CPU / GPU / 内存百分比，每张卡片是「数值 + 整宽进度条」；
  进度条在 100% 时变红。
- **顶栏**：左侧是 PC 已运行时间（`HH:MM:SS`，AIDA64 原始值含天数时才显示 `xxD `
  前缀），右侧是电量。插上会枚举数据的 USB 口时，电量左侧显示绿色 USB 标志；
  纯充电器只给 5V、不枚举数据，因此不显示。
- **数字滚动**：数值、运行时间与电量按单个数字滚动更新，且增减方向不同时滚动方向
  也不同。
- **本地刷新兜底**：超过 2 秒没有新数据时，各项数值与运行时间显示 `-`，
  避免把卡死的主机当成实时状态。
- **连接状态常显**：左下角始终显示 `无 Wi-Fi` / `已连接` / `连接中` /
  `PC 离线` 之一。
- **设置页**：屏幕亮度（10% 步进，10%~100%）、Wi-Fi 配网、横屏方向、设备信息。
  亮度与方向写入 NVS，开机自动恢复。
- **SoftAP 配网**：开启 `AIPassport-Setup` 热点，用手机扫描周边网络、选择 SSID，
  再填入密码与 PC 地址，配置保存在 NVS；配网页为黑底点阵风格。
- **终端观感**：纯黑背景、白色文字、全部直角。文字使用缝合像素字体的 24px 与
  12px 子集，存放于 `assets/fonts/app_font_24.c` 与 `assets/fonts/app_font_12.c`；
  两者都按字体 12px 设计网格的整数倍生成，因此是点对点显示。源字体及其
  [OFL-1.1 授权](assets/README.zh_CN.md#字库fonts)见资源目录说明。

## 交互

三个按键为 `UP`、`DOWN`、`OK`。

**监控主页**

- `OK` 长按：进入设置页；短按不动作。

**设置页**

- `UP` / `DOWN`：移动选择，当前行显示 2px 白色光标框。
- `OK`：进入当前条目。
- `OK` 长按：返回监控主页。
- `亮度`：进入后光标框转为绿色，`UP` / `DOWN` 以 10% 步进调整，`OK` 结束调节。
- `方向`：`OK` 在两种横屏方向之间翻转 180° 并保存。
- `Wi-Fi`：`OK` 进入二次确认页，确认页 `OK` 开始配网，`UP` / `DOWN` 取消。
- `设备信息`：只读页，显示已配置的 PC 地址与需要添加的 AIDA64 传感器名称。

**配网态**（确认 Wi-Fi 配网后进入）

- 停止监控，设备开启 `AIPassport-Setup` 热点。
- 手机打开 `http://192.168.4.1`，扫描并保存网络。
- `OK` 长按：不保存直接退出配网。

## AIDA64 设置

1. 在 AIDA64 里启用 RemoteSensor / LCD 的 HTTP 服务，记下端口（默认 80）。
   设备固定请求 `http://<地址>:<端口>/sse`。
2. 在 LCD 项目里添加传感器项。识别只看 Label 里的关键词，值由 AIDA64 填：

| 显示位置 | Label 需同时包含 | 例子 |
| --- | --- | --- |
| CPU 卡片 | 设备词 `cpu` 或 `处理器` | `CPU Utilization` |
| GPU 卡片 | 设备词 `gpu` 或 `显卡` | `GPU Utilization` |
| 内存卡片 | 设备词 `memory`、`ram` 或 `内存` | `Memory Utilization` |
| 顶栏运行时间 | `uptime`、`up time`、`运行时间` 或 `开机时间` | `UpTime` |

3. 利用率类词：`util`、`usage`、`load`、`rate`、`occup`、`占用`、`使用率`、
   `使用`。设备词与利用率类词必须同时出现，只满足一个则该记录被忽略。
4. 取值：解析器取该条记录里**最后一个数字**作为百分比（因此兼容
   `CPU #1 Utilization 12 %` 这种 Label 自带数字的情况），并把值夹在 0–100。
5. 运行时间的值可以是 `1:23:45`、`0:12`、`1 day 2:03:04` 或 `3d 00:34:13`；
   仅当原始值含天数时，顶栏才在时分秒前显示 `xxD `。
6. 单条 LCD 项的显示文本超过 160 字节会被整条丢弃（同帧其它项不受影响），
   所以 Label 尽量短。

解析器读取 `/sse` 流的 `data:` 记录，按 `{|}` 切分，每段是 `<元素id>|<显示文本>`；
不匹配任何关键词的 LCD 项会被忽略，因此多添加项不会干扰显示。

## 说明

- 面板物理尺寸是 240 x 320 竖屏；BSP 交换 X/Y 使本应用以 320 x 240 横屏运行。
  若你的安装方式下画面上下颠倒，用设置页的「方向」翻转即可。
- 利用率标签同时匹配英文与部分本地化写法，用英文标签最通用。
- 扫描 Wi-Fi 时射频切换信道，配网热点会短暂停顿。
- 配网页的 Wi-Fi 扫描在点击处理修复后尚未在设备上复测；本文其它行为均已在
  硬件上确认。
- 从 `0x0` 刷入合并的 `full.bin` 会重写 NVS，因而清空已保存的 Wi-Fi 配置；
  只刷 `0x10000` 的应用镜像可以保留。
